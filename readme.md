# Omni Gacha
All item entries created by *CyberQueenJolyne*, *Desolatesabers*, and *Argotherat*
## What is this thing?
Omni Gacha is a gacha based on the chaos gacha for use in creating fanworks.
## How do I use it?
the site itself is mostly a prototype right now while I put it together. information regarding usage can be found [here](https://docs.google.com/spreadsheets/d/1COj1RLQo87SG9lSbi3BjQ_weRz3M7wQFz8H84jqxvqE/edit?gid=1104568683#gid=1104568683)
## Can I contribute?
please, please, please, please, please, please, please, please, please, please, please-
No vibecoding though. just make a pull request and if that makes it into main eventually it'll end up in prod.
## There's a production branch?
Production branch (prod) is what the site actually runs on, so that it isn't being randomly changed while main gets updated with stuff.
